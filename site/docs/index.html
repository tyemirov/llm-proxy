GET / getText

Generate text from a query prompt

Authentication: TenantClientKey (query key)

Parameters

NameLocationRequiredTypeDescription
keyqueryYesstringTenant client secret.
promptqueryYesstringUser prompt.
providerqueryNostringCanonical provider identifier. Omission uses the tenant default.
modelqueryNostringModel identifier. Omission uses the resolved provider default.
web_searchqueryNostringBoolean-like query value accepted by the legacy query operation.
system_promptqueryNostring
max_tokensqueryNointegerInitial per-attempt output budget. The same budget is reused when the proxy requests a missing suffix; after a zero-text output-budget stop, a configured model output limit bounds any generic increase.
reasoning_effortqueryNostringNon-blank effort supported by the resolved route. Omission selects the tenant or route default.
formatqueryNostringPreferred response media type. Unknown values select text/plain.
AcceptheaderNostringResponse media preference used when format is omitted.
X-LLM-Proxy-Request-Timeout-SecondsheaderNointegerA positive whole-second request budget no greater than the server maximum. Omission selects the configured default.

Request body

None.

Responses

StatusContent typesHeadersDescription
200text/plain, application/json, application/xml, text/csvX-LLM-Proxy-Request-Timeout-Seconds, X-LLM-Proxy-Request-Tokens, X-LLM-Proxy-Response-Tokens, X-LLM-Proxy-Total-TokensComplete generated text in the selected representation. The proxy internally continues exact output-budget stops through one provider-neutral lifecycle: OpenAI Responses incomplete/max_output_tokens, OpenAI-compatible Chat Completions length, Gemini MAX_TOKENS, and Anthropic max_tokens. HTTP 200 is returned only after the selected transport reports its complete signal: OpenAI completed, Chat stop, Gemini STOP, or Anthropic end_turn|stop_sequence. Intermediate, safety, refusal, tool, malformed, missing, and unknown states never return text as success.
400text/plain, application/jsonX-LLM-Proxy-Request-Timeout-SecondsThe request is malformed, names an invalid route/capability, or supplies an invalid timeout. Text validation failures use the canonical plain-text error. Timeout-header validation uses the canonical JSON error.
403text/plainnoneThe tenant client key is absent or unknown.
429application/jsonX-LLM-Proxy-Request-Timeout-Seconds, X-LLM-Proxy-Request-ID, Retry-AfterThe selected upstream provider returned HTTP 429. The proxy preserves 429 at its public boundary and returns only sanitized provider metadata; it never exposes the raw provider body or message.
499nonenoneThe caller canceled or closed the request.
502application/jsonX-LLM-Proxy-Request-Timeout-Seconds, X-LLM-Proxy-Request-ID, Retry-AfterThe selected upstream provider failed, returned a non-429 unsuccessful HTTP status, or returned an unusable success payload. Output-budget stops are continued internally and do not create this response. The response contains only sanitized provider metadata and never exposes partial generated text, token-count headers, a raw provider body, or a provider error message; provider-reported usage can still be retained in managed failure accounting.
503text/plainX-LLM-Proxy-Request-Timeout-SecondsThe selected provider is not configured or the bounded request queue is full.
504text/plain, application/jsonX-LLM-Proxy-Request-Timeout-SecondsThe proxy request budget or upstream operation timed out.

PUT /api/management/tenants/{tenant_id}/provider-keys/{provider} putManagementProviderKey

Verify and save provider settings and a provider credential

A nonempty api_key performs exactly one provider-authenticated verification operation for the selected provider and text model under the management request context and shared upstream admission/rate-limit boundary. Only a successful verification atomically persists the credential and submitted settings, reconciles routing defaults, and returns a keyed profile. Rejection and unconfirmed transient outcomes never mutate the provider key, settings, defaults, or managed usage. An empty api_key retains the existing verified credential while updating settings without reverification.

Authentication: TAuthSession (cookie app_session_llm_proxy)

Required Content-Type: application/json

Parameters

OriginheaderNostringWhen supplied, must exactly match the configured public origin for mutations. Matching origins receive credentialed CORS headers.

Request fields

FieldRequiredTypeDescription
api_keyYesstringAn unverified new or replacement provider key. A nonempty value is verified against the exact path provider and selected text_model before any persistence. Send an empty string to retain the tenant's existing verified credential while updating its provider model or system prompt; an empty value is rejected when no credential exists.

POST /v2/analyze postV2Analyzer

Analyze hash-bound evidence with strict structured output

The evidence-grade analyzer operation. It accepts ordered system and user messages containing typed text, image, or audio parts, requires a named strict JSON Schema, and returns only one complete schema-constrained JSON object. Binary bytes are canonical base64 and independently verified against their lowercase SHA-256 before provider admission. The current OpenAI Responses adapter supports text and ordered image parts; audio and every unsupported provider/model capability return 400 before upstream work.
