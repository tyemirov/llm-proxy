Clear boundaries

Capability is route-specific.

LLM Proxy does not pretend every provider behaves the same. The selected provider and model must explicitly support each requested capability.

  • Web search is available only on the OpenAI models marked in the catalog.
  • Image and audio message attachments are accepted only on models that declare those media inputs.
  • Reasoning effort values are validated for the exact route; unsupported values fail before provider dispatch.
  • Known output limits are enforced by the proxy. Otherwise, the upstream provider remains authoritative.
